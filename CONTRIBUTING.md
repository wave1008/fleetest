# Contributing

[日本語](#日本語)

Thank you for your interest in fleetest. It is in beta.

## Bug reports and feature requests are welcome

Open an issue: [Bug report or feature request](https://github.com/wave1008/fleetest/issues/new/choose).

- Check [Troubleshooting](docs/user-docs/in_action/troubleshooting.md) first.
- For a bug, include the output of `fleetest --version` and, if you can, the zip from `fleetest doctor --bundle fleetest-diag.zip`. **Issues are public, and the zip can contain on-screen text from your app — review it before attaching.**
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in an issue.

## Pull requests are not accepted

The maintainer makes all code changes. Please open an issue instead of a pull request — describe the problem, and a proposed fix in the issue is welcome. Pull requests may be closed without review.

The reason: fleetest is maintained with its own rules, verification gates and device test suites (documented in Japanese in [CLAUDE.md](CLAUDE.md) and [docs/](docs/README.md)), so changes are made and verified on the maintainer's side.

You are free to fork fleetest under the [MIT License](LICENSE).

## 日本語

fleetest に関心を持っていただきありがとうございます。fleetest はベータ版です。

- **不具合の報告と要望は Issue で受け付けます**([不具合の報告・要望](https://github.com/wave1008/fleetest/issues/new/choose))。先に [トラブルシューティング](docs/user-docs/in_action/troubleshooting_ja.md) を確認してください。
- 不具合の報告には `fleetest --version` の出力と、可能なら `fleetest doctor --bundle fleetest-diag.zip` の zip を添えてください。**Issue は公開され、zip にはアプリの画面の文字が入ることがあります。添付する前に中身を確かめてください。**

- **プルリクエストは受け付けていません。** コードの変更はすべて保守者が行います。プルリクエストの代わりに Issue を開いてください(直し方の提案を Issue に書くのは歓迎します)。プルリクエストはレビューせずに閉じることがあります。
- fleetest は独自の規則・検証の関門・デバイスのテストスイート(日本語で [CLAUDE.md](CLAUDE.md) と [docs/](docs/README.md) にあります)で保守しているため、変更と検証は保守者の側で行います。
- [MIT ライセンス](LICENSE)の範囲で、自由にフォークできます。
